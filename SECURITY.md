# Security policy

This is an unofficial experimental browser-routing project, not a security boundary and not a Mullvad-supported product.

Before reporting a routing issue, reproduce it with the current source build and include the browser version, Mullvad app version, Windows version, expected route, actual route, and whether the helper health check passed. Do not include account numbers, home addresses, full browsing histories, or public IP addresses in public reports.

For a private vulnerability report, use GitHub's private vulnerability reporting feature if it is enabled for the repository. Otherwise contact the repository owner privately rather than opening a public issue containing exploit details.
